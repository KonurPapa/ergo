The detail pane (TaskDetail) for a failed task, with its details collapsed and expanded.

From top to bottom: the section it sits under in TODO.md, the task title, and **one status line** ("Last run failed · Oct 24 · see Notes"). Clicking the status line opens **Details**: status, priority, queue, blocks, tools and source line, which stay hidden by default. Below that are the bar-style tabs and the active panel. A panel's own actions, such as **Edit**, sit in a small header row inside the panel. The footer holds the model chip, an icon-only Queue button and one primary action (**Run**, **Run again**, or **Stop** while running).

Removed from the old pane: the "All runs" back link and TODO breadcrumb, the always-visible Status / Line / Tools rows, the red "last run failed" banner (the status line and the Notes tab already say it), and the Overview tab (now Brief).
