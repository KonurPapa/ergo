Approach

toggleList() currently rewrites the whole list. Scope it to the selected items and keep siblings untouched. See ERG-143.

  • Read the selection range from the editor state
  • Convert only those items; split the list if needed
src/editor/Bullet.tsx
export function toggleList(state: EditorState, type: ListType) {
  const items = selectedItems(state) // was: allItems(state)
  return items.reduce((tr, item) => setListType(tr, item, type), state.tr)
}
